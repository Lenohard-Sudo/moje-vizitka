# Osobní portfolio & online vizitka 🚀

Jednoduchá, moderní a plně responzivní webová vizitka, kterou jsem vytvořil jako čerstvý absolvent střední IT školy (maturita 2026). Web slouží pro rychlou prezentaci mých dovedností, projektů a jako rozcestník pro kontaktování.

## 🔗 Živé demo
Web je plně funkční a můžete si ho prohlédnout zde:  
👉 **[https://lenohard-sudo.github.io/moje-vizitka/]**

## 🛠️ Použité technologie & nástroje
* **HTML5** – sémantická struktura webu.
* **CSS3** – moderní stylování (Flexbox) a kompletní responzivita pro mobilní zařízení.
* **GitHub Pages** – hosting a automatický deployment přímo z repozitáře.
* **Adobe Photoshop** – úprava a optimalizace profilové fotografie pro web.

## 💡 Co jsem se na tomto projektu naučil a procvičil?
* Základy moderního webdesignu a kódování čistého HTML/CSS bez použití externích knihoven.
* Základní práce s verzovacím systémem Git.
* Optimalizace obrázků (formát, velikost, komprese) pro rychlé načítání webu.
